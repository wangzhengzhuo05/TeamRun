Web Smoke Runtime

自动配对状态是否足够简单、安全且可恢复？

这个原型检验 supervisor、Vite、本地 Runtime、浏览器 credential 与两条基础 smoke 路径之间的状态转换。它不连接真实服务器，也不会运行 Agent；请通过场景按钮检查哪些操作应被允许、阻止或要求恢复。

范围边界 Web 端只证明单任务、低并发、短超时的基础链路。大规模任务、长时间运行、多 Agent 并发、资源压力和正式验收属于桌面端与真实云服务器阶段。
