# Reuse the Personal Work-Item Flow

TeamRun will not add a separate Personal Task entity: a claimed Team Task enters the existing Personal Space work-item and workspace creation flow, which links it to a private Git or folder workspace and Agent session. This keeps Team Task responsibility and status shared while reusing current local, SSH, and paired-runtime behavior; the trade-off is that Team Task links must be added to the existing provider-oriented workspace metadata without turning private workspace state into Team data.
